# Human plans

1. Search existing plans before creating a new plan or step.
2. Read versions, feedback and evidence to determine remaining human actions.
3. Keep stable step keys and idempotency IDs. Use optimistic concurrency where supported.
4. Record requirements, prerequisites, expected results, visible feedback and recovery instructions.
5. Protected secrets, passwords, MFA, and provider approvals remain outside chat.
6. Human confirmation, agent report and independently verified execution are distinct evidence.
7. Preserve the familiar plan view and all existing records; never silently overwrite plan data.
